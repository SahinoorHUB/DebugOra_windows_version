## Install

1. Download the `.zip` archive for your version.
2. Extract the archive (Windows 10/11 built-in support).
3. Run `Debugora.exe`.

**Requirements:** Windows 10 or 11 (64-bit), [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/), and `adb` in PATH (Android platform-tools). Node.js is bundled.
